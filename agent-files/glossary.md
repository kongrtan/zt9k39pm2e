# 용어집

운영자가 채팅에서 쓰는 줄임말과 조직 내부 용어. Agent는 이 뜻으로 해석한다.

| 용어 | 뜻 |
|---|---|
| 정산배치 | `batch-settle` 서비스 |
| PG | 외부 결제대행사. 연동은 `ext-pg-gateway`를 거친다 |
| 1티어 | 장애 시 매출에 바로 영향을 주는 서비스 (`service-catalog.csv`의 `tier = 1`) |
| 롤백 | `ROLLBACK_DEPLOY` 조치. 2인 승인이 필요하다 |
| 재기동 | `RESTART_SERVICE` 조치 |
| 증설 | `SCALE_OUT` 조치 |
| 캐시 비우기 | `CLEAR_CACHE` 조치 |
| 당직 | 근무 시간 외 1차 대응 담당 |
| 런북 RB-xxx | 지식 검색 "장애 런북"에 있는 문서 번호 |
